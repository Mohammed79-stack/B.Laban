## 📖 About the Project
 
B.Laban is a dessert brand that started in Egypt and is known for rice pudding based desserts and a colorful, social-media-friendly style. I wanted to practice turning a modern food brand's look and feel into a polished, responsive website.
 
This project is a **UI/UX recreation and concept design**, built from scratch with my own code, trying new CSS unit:
 
- Building a clean, responsive layout
- Designing menu and product sections
- Working with animations and smooth interactions
- Organizing a real project with reusable components
## ✨ Features
 
- 🍮 Hero section with a strong first impression
- 📋 Menu / products showcase
- 🎞️ Smooth animations and hover effects
